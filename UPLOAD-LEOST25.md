## 🔧 SE DER ALGUM ERRO

### Erro: "remote origin already exists"
```bash
# Remover conexão antiga
git remote remove origin

# Adicionar novamente
git remote add origin https://github.com/LeoST25/autenticacao-jwt.git
```

### Erro: "Authentication failed"
- Use **Token de Acesso Pessoal** instead da senha
- Configure em: GitHub → Settings → Developer settings → Personal access tokens

### Erro: "Repository not found"
- Certifique-se de ter criado o repositório primeiro no GitHub
- Verifique se o nome está correto: `autenticacao-jwt`
