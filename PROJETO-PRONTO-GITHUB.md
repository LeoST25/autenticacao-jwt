### PASSO 1: Criar Repositório no GitHub

1. **Acesse:** [github.com](https://github.com)
2. **Clique em:** "New Repository" (botão verde)
3. **Configurações recomendadas:**
   - **Nome:** `autenticacao-jwt` ou `sistema-auth-jwt`
   - **Descrição:** `Sistema completo de autenticação com JWT, Node.js, Express e MongoDB`
   - **Público:** ✅ Sim (recomendado para portfólio)
   - **README:** ❌ Não adicionar (já temos)
   - **Gitignore:** ❌ Não adicionar (já temos)  
   - **Licença:** ❌ Não adicionar (já temos)

4. **Clique em:** "Create repository"

### PASSO 2: Conectar e Fazer Upload

```bash
# 1. Adicionar repositório remoto (substitua SEU_USUARIO)
git remote add origin https://github.com/SEU_USUARIO/autenticacao-jwt.git

# 2. Verificar se foi adicionado
git remote -v

# 3. Fazer upload para GitHub
git push -u origin main
```

### PASSO 3: Personalizar Informações

Após o upload, edite os arquivos e substitua:

#### No README.md:
- `seu-usuario` → seu username do GitHub
- `Seu Nome` → seu nome real  
- `seu.email@exemplo.com` → seu email

#### No package.json:
- `"author": "Seu Nome <seu.email@exemplo.com>"` → suas informações
- URLs do repositório com seu username


## 📞 SUPORTE

Se encontrar problemas:

1. **Verifique as credenciais do Git:**
   ```bash
   git config --global user.name
   git config --global user.email
   ```

2. **Se der erro de permissão:**
   - Use token do GitHub instead da senha
   - Configure SSH keys

3. **Para desfazer algo:**
   ```bash
   git reset --soft HEAD~1  # Desfaz último commit
   git checkout -- arquivo  # Desfaz alterações
   ```
